# Platform logos — sources

All marks are the unaltered SVG files from **Simple Icons v16.37.0** (`simple-icons` npm package, `icons/<slug>.svg`; project licence CC0-1.0, https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
They are rendered in one colour (navy-500, navy-700 on hover) through a CSS mask; the paths are not edited.
Marks remain trademarks of their owners. Used nominatively to say which platforms RP secures and works in; never as "partner", "trusted by" or "certified".
Simple Icons asks users to read its disclaimer: https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md

## Left out
AWS, Microsoft Azure, Microsoft 365 / Sentinel, CrowdStrike and OpenAI are not in Simple Icons (removed or never added at the brands' request), so there is no clean CC0 source. Their own trademark rules restrict logo use to licensed partners or need permission. Add them only from an official kit with written OK.
